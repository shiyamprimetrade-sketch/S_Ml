# Project charter

Purpose: learn useful relationships from authorized observations, measure them
against held-out evidence, and improve through recorded experiments. TikTok is
the first mission; the engine remains separately installable from S, S-Brain,
S-Eye and S-Hand. Owner: Shiyam Talukder.

Facts, correlations, predictions, hypotheses, experimental results and unsupported
claims must remain distinguishable. Fixed diagnostics are not learned models.
Publication is separate from analysis and draft generation. No publishing,
engagement automation or credential collection is implemented in this milestone.

Acceptance for the foundation: executable training, gradient verification,
baseline comparison, exact checkpoint restore, real authorized ingestion locally,
persistent deduplication, a functional read-only dashboard HTTP API, tests, CI
and a resumable GitHub checkpoint. This is a subset of full mission acceptance.

Full acceptance additionally requires actual horizon-labelled outcomes, evaluated
TikTok predictions, secure independent authorization, restart-persistent polling,
model promotion/rollback, tested mobile dashboard controls, deployment and a
versioned production release. Never infer these from synthetic tests.
